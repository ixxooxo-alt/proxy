# R20-F02：新增保留名称会改变 sing-box 完整版的私密产物

**确认；P2；类别：完整版兼容性、文档不符。** 不代表现有 14 个公开文件有变化。

## 位置

- `generator/emit_singbox.py:143–147`：reserved_tags 合并完整版与简易版组名，新增境外DNS。
- `build.py:268–272`：只转换一次节点，把同一批转换结果用于两种版本。
- `generator/nodes.py:430–465`：节点名命中 reserved 时改名。
- `tests/test_simple.py` 中 reserved_tags 的断言接受两版并集，没有检查旧版私密输出的兼容性。

## 为什么错、复现依据

使用同一个虚构 SOCKS5 输入，名称为“境外DNS”（无真实节点或凭据），按构建入口同样的 load → build_plan → nodes.convert(reserved_tags) → emit_singbox.build 路径分别在 r19 628ed8a 和本提交生成**完整版**：

- r19 节点标签：境外DNS。
- r20 节点标签：境外DNS（节点），renamed 映射回原名。
- 完整版 JSON 不相同。

这是 r19 合法输入。完整版本身没有境外DNS组，却因为同时生成简易版而改了节点标识。按原名筛选仍能保持地区归属；但“完整版生成结果不改”已不成立。旧缓存选择、依赖标签的外部操作是否受影响取决于客户端，不把它们说成本轮已复现的现象。

代码位置即直接依据：[reserved_tags](https://github.com/ixxooxo-alt/proxy/blob/4d3349d8492decae66eef328d0652f7c0ebd4ff1/generator/emit_singbox.py#L143-L147)、[构建调用](https://github.com/ixxooxo-alt/proxy/blob/4d3349d8492decae66eef328d0652f7c0ebd4ff1/build.py#L268-L272)。

## 建议

按输出布局分别计算保留名、分别转换/重命名，完整版继续使用 r19 的保留集合；简易版额外避开境外DNS。转换报告应说明两种产物的命名差异。补一个含该名称的虚构输入，比较完整版两种 sing-box 版本的生成结果；已有“两个版本都避开所有组名”的测试也应随需求调整。
