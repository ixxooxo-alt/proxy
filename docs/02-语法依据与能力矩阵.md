# 语法依据与能力矩阵

查阅日期：2026-09-23。“源码”指从官方仓库对应标签取得的代码；“文档”指官方文档站或仓库内文档。

## 目标版本与依据

| 客户端 / 内核 | 目标版本 | 依据 |
|---|---|---|
| mihomo（Clash Verge Rev、CMFA、内核） | v1.19.x，按 v1.19.31 核对（当时最新标签） | 源码 `config/config.go`、`adapter/outboundgroup/*.go`、`adapter/provider/parser.go`、`adapter/outbound/direct.go`；https://wiki.metacubex.one/config/ |
| Clash Verge Rev | v2.5.x（最新标签 v2.5.5） | 只核对了版本号；内置 mihomo，配置字段按上一行 |
| Clash Meta for Android | v2.11.x（最新标签 v2.11.34） | 只核对了版本号；内置 mihomo |
| sing-box（SFA） | 1.14.x（按 v1.14.1）；另出 1.12–1.13 兼容版 | 仓库内文档 `docs/configuration/**`、`docs/deprecated.md`，源码 `option/*.go` |
| Loon | 3.x（规则优先级说明要求 3.0.3+） | https://nsloon.app/docs/ 的“规则”“策略组”“节点筛选”“DNS”“DNS 映射”页；官方示例 https://github.com/Loon0x00/LoonExampleConfig/blob/master/example.conf （外部审核后补查）；另对照社区配置 |
| Quantumult X | 1.x | 官方 https://github.com/crossutility/Quantumult-X/blob/master/sample.conf；匹配顺序官方未写明，参考社区文档 https://qx.atlucky.me/ |

不同客户端的字段、策略名、规则关键字分别按各自依据生成，没有互相替换关键词冒充适配（例如 Quantumult X 用 `host-suffix` / `static` / `available`，不用 Loon 的写法）。

## 能力矩阵

标记：✅ 原生支持　🔧 需额外适配（已做）　❌ 不支持　❓ 尚未验证（没有设备 / 官方说明不足）

## 平台变体

| 客户端 | 平台 | 产物 | 配置差异 |
|---|---|---|---|
| Loon | iPhone / iPad / Mac（官方支持的设备与版本） | `loon/loon.conf` | 无，共用；平台验收分别记录 |
| Quantumult X | iPhone / iPad / Mac（官方支持的设备与版本） | `quantumultx/quantumultx.conf` | 无，共用；平台验收分别记录 |
| Clash Verge Rev | Windows / macOS | `mihomo/mihomo-profile.yaml` | 配置相同；差异在客户端设置（TUN 服务模式、系统授权） |
| Clash Meta for Android | Android | `mihomo/mihomo-profile.yaml` | 配置相同；TUN 由 VpnService 提供 |
| mihomo 内核 | Linux / 路由器等 | `mihomo/mihomo-core.yaml` | 多出端口、控制面、TUN 开关 |
| SFA | Android | `sing-box/sing-box-1.14.json`、`sing-box-1.12.json` | 规则集下载方式不同（1.14 用 http_clients，1.12–1.13 用 download_detour） |

“商店能否安装”“配置能否导入”“功能是否通过验收”三件事在 `docs/05-验收记录.md` 里分别记录，目前都未在真机上验证。
