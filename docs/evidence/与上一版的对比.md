## 五、公开产物（配置文件）：r13 → r14 改了什么

每个产物按“分段”拆成一条一条来比（去掉注释）：Loon / Quantumult X 按 `[分段]` 逐行；mihomo 按策略组、规则、DNS、其余设置；sing-box 按 DNS 服务器、DNS 规则、路由规则、规则集、出站与策略组、其余设置。节点筛选正则换成了标记：`<筛选：上一版 hk>` / `<筛选：上一版严 hk>` 是 r13 的（r13 每个地区只有一条筛选时没有后一种），`<筛选：宽 hk>` / `<筛选：严 hk>` 是 r14 的两条。很多条目改法相同、只是各自的地区或各自的地址不同时，合并成一条，写成“各自的地区”“各自的地址”。“顺序”指两版都有的条目，先后是否相同。规则这类没有名字的条目，一条删除和一条新增文字很像时会配成一条“改动”显示（标题后面带“…”），只是为了紧凑：配成一对不代表一条规则改成了另一条，按后面的“去掉 / 加上”读。
