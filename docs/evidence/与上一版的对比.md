生成方式：`python3 tools/compare_versions.py --old <r12 交付包解压后的工程目录> --old-label r12 --new-label r13 --write`。r12（统一源 2026.10.06-1） 的筛选正则由它自己的生成器算出来，r13（统一源 2026.10.06-1） 的取自当前统一源；两者都用 Python 执行（当前这一版另有 ICU 与 mihomo 官方内核的对比，见 `icu-check.log`、`official-check.log`）。产物对比用的是两版各自 `dist/` 里的文件。
