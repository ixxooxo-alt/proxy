# 导入、更新、诊断与回滚

## 导入前

1. 确认客户端版本满足 `docs/02-语法依据与能力矩阵.md` 里的版本要求。
2. 把配置里的订阅占位链接换成你的订阅（或用 `build.py` 在本机生成 `dist/private/` 版本）。有 `source/local.yaml`（固定节点、公司内网等个人覆盖）时，要导入的是 `dist/private/` 里的那份：公开的 `dist/` 始终不含个人覆盖。
3. 先在一台设备上导入、按 `docs/05-验收记录.md` 的真机清单走一遍，再推广到其他设备。
4. 保留当前正在用的旧配置文件，出问题时直接切回（见“回滚”）。

## 各客户端

**Loon（iPhone / iPad / Mac）**：导入 `loon.conf`。节点按 `[Remote Filter]` 里的名称正则分到地区（正则由词表生成，每条约 10 KB，不要手改；见下面“节点按名称分地区”）；
广告集合来自 `[Remote Rule]`；本配置没有插件、复写、脚本和证书。需要可莉等第三方去广告插件时自行在 `[Plugin]` 添加，
插件规则的优先级介于本地规则和订阅规则之间（官方文档）。

**Quantumult X（iPhone / iPad / Mac）**：导入 `quantumultx.conf`。节点由 `server-tag-regex` 按名称分到地区（同上，由词表生成）；
广告集合在 `[filter_remote]`；`[mitm]` 为空，本配置不需要证书。

**Clash Verge Rev（Windows / macOS）** 与 **Clash Meta for Android**：导入 `mihomo-profile.yaml`。
端口、TUN、控制面由客户端自己的设置决定，文件里不写。首次启动内核会从 jsDelivr 镜像下载 GeoSite / GeoIP 数据。
Windows 使用 TUN 需要客户端的服务模式，macOS 需要授权——这属于客户端设置，不在配置文件里。

**mihomo 内核直接运行**：用 `mihomo-core.yaml`。只监听本机（混合端口 7890、控制面 127.0.0.1:9090，未设 secret）。
如果要让局域网或远程访问控制面，必须先加 `secret` 并确认监听范围。TUN 默认关闭，开启需要权限。

**SFA（Android，sing-box）**：sing-box 不支持订阅，必须用 `build.py --singbox-sub-url` 或 `--singbox-nodes` 在本机生成
`dist/private/sing-box-1.14.json`（SFA 1.14 及以上）或 `sing-box-1.12.json`（1.12–1.13），再以“本地配置”导入。
公开的 `dist/sing-box/*.json` 是没有节点的模板，所有代理组都指向“无可用节点”（拒绝连接），不能直接用。
首次启动要经“国外默认”下载规则集，所以节点必须先能用。

## 节点按名称分地区：怎么检查、怎么补

四个客户端用的是同一套规则，来自 `source/regions.yaml` 的词表（规则说明见 `docs/02`“节点名称分地区”）。它只看节点的名字，名字写错地区就会分错，也不证明节点实际从哪里出去。

**导入后先看一眼**：打开“香港·手动”“日本·手动”“美国·手动”等组，确认里面是对应地区的节点；再看“其他地区”，里面应该只有别的国家的节点和认不出名字的节点。发现下面任何一种情况都告诉我，并先切回上一份配置：导入时报正则错误；某个地区组是空的，而订阅里明明有这个地区的节点；所有节点都挤在“其他地区”。

**在电脑上列出每个节点进了哪个组**（只需要节点名，不需要订阅链接，不联网）：

```bash
python3 tools/check_node_names.py 节点名.txt             # 每行一个节点名（从客户端的节点列表里抄下来或复制出来）
python3 tools/check_node_names.py --clash 订阅.yaml      # 或者给一份 Clash / mihomo 格式的订阅文件，只读其中的节点名
```

报告默认只列需要你看的：没认出地区的（进了“其他地区”）、说不清落地所以两个组都进的、按中转 / 让位规则判断的、被当成信息节点的。加 `--all` 列出全部。用 `build.py --singbox-nodes / --singbox-sub-url` 生成 sing-box 配置时，同样的报告会自动写到 `dist/private/节点分组报告.txt`。

没有电脑、只用手机时：把节点列表截图或把节点名发给我（只要名字，不要订阅链接），我来跑这份报告。

**某个节点没认出来或分错了**：复制 `source/local.example.yaml` 为 `source/local.yaml`，在 `node_names` 里补，然后 `python3 build.py`，导入 `dist/private/` 里的配置（本地补充只进私密产物，公开的 `dist/` 不变）：

```yaml
node_names:
  extra_words:
    us: {words: [圣路易], latin: [STL]}       # 给美国补一个中文词、一个英文代码；地区 id：hk jp kr tw sg us，其他国家写 other
  assign:
    - {name: "Premium 01", region: jp}        # 名字里完全看不出地区的，直接指定（写完整节点名）；region 写 none 表示哪个组都不进
```

如果这个写法很多机场都在用，告诉我，我把它加进统一源的词表。

## 用官方工具自检（强烈建议）

```bash
mihomo -t -d . -f mihomo-core.yaml              # mihomo 官方解析检查
sing-box check -c dist/private/sing-box-1.14.json
```

也可以用 `tools/check_official.py` 一次检查全部公开模板和一份带样例节点的 sing-box 配置（官方程序从各项目 GitHub Releases 下载，核对发布页的 SHA-256）。注意 `sing-box check` 只做解析和初始化，不执行完整启动，通过也不等于运行时一定正常。

Loon、Quantumult X 没有命令行检查工具，只能导入 App 看是否报错。它们的节点筛选正则另用 `python3 tools/check_icu.py` 在 ICU 正则引擎上跑过一遍（推断这两个 App 用的是苹果系统自带的、基于 ICU 的正则），这不等于在 App 里验证过。

## 诊断：某个网站走了哪个组

- mihomo（Clash Verge Rev / CMFA）：连接面板里能看到命中的规则和代理链。
- sing-box：把 `log.level` 临时改成 `debug`，日志会打印命中的规则。
- Loon / Quantumult X：最近请求 / 日志里能看到命中的策略。

对照 `docs/04-规则清单与证据.md` 查这个域名应该归哪个组；不一致时先看“已知限制”里是否是各端语义差异。
mihomo 系客户端可以把连接记录交给 `tools/check_connections.py` 自动对照（采集方法见 `docs/09-真机验收操作清单.md` 第 6 节）。
查出口 IP 的网站只能说明“它自己”走了哪个出口，不能证明其他业务走同一出口。

## 更新

1. 改 `source/`（或更新到新的统一源版本）→ `python3 build.py` → `python3 -m unittest discover -s tests`（或 `bash tools/run_checks.sh`，任何一步失败都会以非零退出码结束）。
2. 生成是“全部成功才替换”：统一源校验、私密产物（订阅下载、节点转换）、写盘前的结构检查，任何一步失败都不改动现有产物；写入时先把所有文件写成临时文件，再逐个替换，替换中途出错会把已替换的恢复成旧版本。进程被强行终止或断电时，目录里可能留下 `.new-*` / `.bak-*` 文件，按文件名手动恢复或删除即可。
3. `dist/manifest.json` 记录统一源版本、源码摘要（含 `build.py`，不含 `local.yaml`）和每个产物的 SHA-256；`python3 build.py --check` 会连 manifest 一起核对。私密产物另有 `dist/private/manifest.json`，另外记录 `local.yaml` 的摘要。
4. 组名保持不变时，客户端会保留你的手动选择；改组名会让该组回到首次默认值。
5. 远程集合（广告、GeoSite / GeoIP）由客户端按自己的周期更新，内容以上游为准，不在本项目版本里（2026-09-30 你决定不锁定版本、跟随上游）。所以同一份配置在不同日期的匹配结果可能不同，排查时先确认远程集合的更新时间。

## 回滚

- 设备上：重新导入上一份配置文件（导入前务必留一份）。2026.10.02-1 这一版把地区筛选正则从每条几百字节换成了约 10 KB，Loon / Quantumult X 上还没验证过；这两个 App 导入后如果报正则错误、地区组为空或明显变卡，先切回上一版（2026.09.30-1）的配置，再把现象告诉我。
- 项目里：`dist/` 就是一份完整产物，按 `manifest.json` 里的版本号保存副本即可；要回到旧统一源时，恢复对应的 `source/` 再生成。
- 远程集合出问题（例如广告集合误杀）：在客户端里临时关闭该远程规则，或把 `广告拦截` 组切到 DIRECT（sing-box 需删掉对应规则后重新生成），再在 `source/adblock.yaml` 补例外。
