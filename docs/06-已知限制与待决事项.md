## 各端语义差异（生成器已按各端处理，但结果不完全一致）

- **Loon / Quantumult X 的广告集合优先级低于本地产品规则**（Loon 官方：本地 > 插件 > 订阅）。domain-list-community 快照里落在产品规则范围内的 30 个广告条目，已全部前置：28 条放进自有拦截（四端都拦），2 条按 GitHub 官方放行清单放进误杀例外（四端都不拦）。仍有差异的是只出现在 blackmatrix7 广告集合里、又位于产品根域下的主机（例如某个 `*.twimg.com` 统计域名）：这两端会走产品组而不是被拦截。mihomo / sing-box 严格按“例外 → 拦截 → 产品规则”执行。
- **上游广告条目连带的影响**：跟随上游拦截的 `analytics.google.com` 同时是 Google Analytics 后台网页，`graph.instagram.com`、`graph.whatsapp.*` 是统计上报主机。需要 GA 后台或遇到相关功能异常时，在 `source/adblock.yaml` 的误杀例外里加对应主机再重新生成。
- **Loon 的“手动优先”**：官方示例说 url-test / fallback 只支持节点、其他会被忽略，现行文档又说策略组支持嵌套。为此 Loon 的手动优先组在两个成员组后附带同地区节点：嵌套生效时是真正的“手动优先 → 自动兜底”；嵌套被忽略时退化为同地区顺序故障转移（不跨国、不直连）。实际是哪种，要在设备上看该组的成员列表确认。
- **Quantumult X 没有 no-resolve**：域名连接走到 Telegram 专属 IP 规则时会先解析。
- **Quantumult X 的策略名**：`Apple Music/TV`、`Disney+`、`Google AI`、`PayPal·美国固定` 等含 `/`、`+`、空格、`·`，官方没有说明是否支持，需真机确认；不支持时只给 QX 换名。
- **Loon / Quantumult X 没有引入国内 / 国外域名大集合**：它们含宽泛关键词规则（例如 `DOMAIN-KEYWORD,jav`、`DOMAIN-SUFFIX,ms`），不符合收录要求。代价是未命中规则的境外域名会被国内 DNS 看到（结果仍走国外默认）。
- **广告数据源各端不同**：mihomo / sing-box 用 domain-list-community 的 `category-ads-all`，Loon / QX 用 blackmatrix7 的 `AdvertisingLite`（38,068 / 38,066 条，2025-12-08 更新）。两者覆盖范围不同。
- **sing-box**：没有故障转移 / 负载均衡组、不能隐藏子组、不支持订阅；广告拦截是规则动作，不能在界面一键关闭；首次启动要经“国外默认”下载规则集，节点必须可用；空组用的 `block` 占位出站在 1.14 已标记弃用（v1.14.1 源码中仍可用），节点转换报告会列出哪些组没有节点；排期：1.16 发布前复查，若被移除，改为生成时去掉空组并在报告中列出受影响的默认出口。不返回 AAAA 时 fakeip 不配置 IPv6 段。
- **mihomo 旧内核**会忽略 `empty-fallback`，筛选为空的组会落到 COMPATIBLE（等同直连）。官方 wiki 已记载该字段但没有写起始版本；请使用较新的 v1.19.x。

## 未覆盖或未证实的内容

- **证据强度**：552 条服务规则（产品 532、服务专属 IP 14、系统联网检测 6）中，25 条来自本次实际查阅的官方文档；16 条来自官方来源但本次没能重新抓取（Telegram IP 段、Gemini API 端点）；490 条来自社区规则集，已按固定快照（domain-list-community `c1c2cf0`、blackmatrix7 `51d2e1d`）逐条核对，全部在对应服务的上游列表里找到；21 条是维护者知识（清单见 `docs/evidence/上游规则对照.md`）。社区来源只说明上游维护者也这样归类，不等于官方确认或实测可用。
- **未收录**：Netflix Open Connect IP 段、ChatGPT 语音需要的 UDP IP 段；上游列表里的防御性注册、公司官网、CNAME 目标、共享设施与用途未核实的主机（取舍见各服务的 `shared_excluded`）。
- **上游快照会过期**：换快照时改 `source/evidence.yaml` 里的 `snapshot`，重新运行 `tools/check_upstream_evidence.py --write`；记录文件每条一行，前后两次的差异就是上游变化对本项目的影响。
- **HTTPDNS**：没有经过验证的条目，未启用。
- **复写 / 脚本 / MITM 去广告**：未内置，不宣称复制可莉配置的去广告效果；需要时自行在 Loon / QX 添加插件并在设备上生成证书。
- **共享主机无法按域名拆分**：X 应用内的 Grok 与 x.com 共用主机，归 X（上游 xai 列表里的 `grok.x.com` 也归 X）；GitHub Copilot 的 `github.com/copilot/*`、`api.github.com/copilot_internal/*` 归 GitHub；B 站接口见上表第 5 项。
- **名称正则只是初筛**：节点名写错地区就会分错组；实际出口要实测记录（`docs/05-验收记录.md`）。
- **健康检查参数**（间隔 300 秒、超时 5 秒、连续 3 次失败触发检查、测速容差 50 毫秒）来自设计，未在真实网络里测量切换和恢复时长。
- **解锁与可用性**：Hulu、Abema、DMM、Bahamut、Bilibili 港澳台等是否能播放都未实测；自动测速通过不代表带宽、解锁或 IP 信誉。
- **远程集合与 GeoIP / GeoSite** 内容以上游为准，会随客户端更新而变化，不属于本项目版本。
